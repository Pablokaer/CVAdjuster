## Design Context

### Users
Job seekers — broad audience, any professional level, any industry. Stressed, focused, typically applying to multiple positions. Context of use: home, evenings or weekends, intermittently. They need a tool that feels credible and fast, not a playground.

### Brand Personality
Sharp, strategic, confident. Career coach energy. The interface should feel like a decisive, capable advisor — not a generic web app. It empowers the user; it doesn't overwhelm them.

Three words: **precise, authoritative, driven**

### Aesthetic Direction
Dark theme (appropriate for the focused, task-at-night use context). Primary accent: purple/violet (#7c6af7). The design should feel editorial and precise — like a premium career tool, not another chatbot wrapper.

**Anti-reference**: the generic "AI SaaS purple glow" monoculture — glassmorphism everywhere, gradient text, glow orbs as decoration, same dark template used by a thousand other tools. That is what this should NOT look like.

### Design Principles
1. **Decisive hierarchy** — every screen has one clear primary action; secondary actions are visually subordinate
2. **Editorial precision** — typography carries the brand authority; type choices should feel intentional and confident, not decorative
3. **Dark but grounded** — dark theme with restrained use of color; no glow for glow's sake
4. **Speed signals confidence** — interactions feel instant; loading states are calm, not anxious
5. **Trust through restraint** — less decoration, more clarity; users trust tools that don't try too hard
